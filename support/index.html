Gangnam program

강남점 입시·취업·데뷔 지원 프로그램 8가지

01

1:1 포트폴리오 지도

입시반과 취업반을 목적별로 분리 운영합니다.

02

면접 클리닉

대학 입시 면접과 게임회사·웹툰 플랫폼 취업 면접을 대비합니다.

03

업계 MOU · 기업대비반

업계 MOU 취업 연계와 목표 기업별 기업대비반을 운영합니다.

04

실무자 세미나

현직 개발자·아티스트·웹툰 작가 세미나를 연 10회 이상 엽니다.

05

게임·웹툰 팀프로젝트반

실제 개발·연재 방식의 협업 프로젝트를 진행합니다.

06

대학교·게임회사 견학

목표 학교와 회사를 직접 보고 준비 방향을 잡습니다.

07

게임 개발자 인큐베이팅

팀 프로젝트를 출시 경험으로 이어가도록 지원합니다.

08

북미·일본 웹툰 데뷔 연계

해외 플랫폼 데뷔까지 준비를 연계합니다.

SYSTEM 01

전담 입시 멘토

목표 대학 선정부터 준비 일정, 학부모 상담까지. 강남점에서 학생의 준비 과정을 함께 점검합니다.

실기력85
포트폴리오88

SYSTEM 02

포트폴리오 클리닉

대학별 평가 기준에 맞춰 담당 강사가 수시로 피드백하고 완성도를 끌어올립니다.

SYSTEM 03

1:1 진로·모의면접

원서 접수 전, 실제 면접과 같은 형식으로 모의면접을 진행하고 즉시 피드백합니다.

SYSTEM 04

입시 세미나

전형 변화와 대학별 최신 정보를 세미나로 빠르게 전달합니다.

SYSTEM 05

콘텐츠 입시박람회

대학 입학처를 직접 만나는 대형 행사. SBS 입시관리의 핵심 프로그램입니다.

52개 대학
SYSTEM 06

SBS 대학 MOU 협약 네트워크

SBS아카데미게임학원 공통 대학 협약 네트워크를 바탕으로, 강남점에서도 목표 전형과 학과에 맞는 입시 준비 방향을 안내합니다.

현장 사진은 SBS 입시센터 프로그램 자료이며, 성장 리포트의 수치는 설명을 위한 예시입니다.
